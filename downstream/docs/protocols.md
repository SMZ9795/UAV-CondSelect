# Protocols

The fixed internal split contains 511/110/109 clean images and 102/22/22 images per generated condition. Each source and all its variants share membership. The reference uses only the 409 extra-clean training sources; paired response measurement uses the disjoint 102 generation sources. External training uses 730 clean images and 146 per retained condition. Real evaluation pools 99 Det-Fly low-light and 31 DUT Anti-UAV snow images; synthetic evaluation uses 117 Simuletic images with 620 instances.

RT-DETRv2-S uses the ResNet-18 backbone, COCO initialization, AdamW, batch 16, LR and weight decay 1e-4, 300-update warmup, and a factor-0.1 drop at successful update 4500. Each run ends at 6000 successful updates and evaluates final EMA. The recorded code detects AMP skips by scale decrease; attempts and image presentations advance on skips, while the successful-update schedule and EMA do not. Weight decay is zero for matching norm/bn parameter groups. Gradient clipping is 0.1. EMA decay is 0.9999 with 2000 warmups. The configurations retain the actual parameter groups and deterministic resize-only transforms.

YOLO11m uses COCO initialization, AdamW, batch 16, LR 3e-4, weight decay 1e-4 on ordinary weights, and no decay on normalization parameters or biases. Betas are (0.9, 0.999), epsilon 1e-8, and clipping is 10. Warmup is 300 successful updates. The cosine schedule has horizon 9000 and final factor 0.01; training ends at successful update 5500. Optimizer post-hooks count successful calls. Skips advance attempts and data consumption; scheduler and EMA advance only on success. EMA decay is 0.9999 with tau 2000. CIoU geometry is evaluated in FP32 by [stable_ciou.py](../src/yolo/stable_ciou.py).

Main comparisons use seeds 0, 1, 2 and all 32 subsets. Internal and external fits are independent. Input images are RGB, directly resized to 960x960 with bilinear interpolation and scaled by 1/255, without randomized image augmentation. Each downstream model starts independently from the official initializer. No gradient accumulation is used.

Matched sampling retains all 1460 entries. The sampler preserves the original shuffled stream and accepts clean entries with probability 1. Each generated condition has the same acceptance probability: 0.8, 0.6, 0.4 or 0.2 for target generated fractions 4/9, 3/8, 2/7 or 1/6. The permutation key is `calibration-uniform-order`; the independent acceptance key is `ratio-thinning-v1`, both hashed with seed and original epoch. Rejected entries do not shorten the 6000-successful-update training budget.

Transfer uses seeds 1, 2, 3 and six arms per seed. The sampler presents 102 clean plus 102 fixed second-view records; the control repeats clean. The stream contains 6800 presentations in 400 attempts of batch 17. AdamW LR and weight decay are 1e-4; warmup lasts 50 attempts. The underlying scheduler milestone is 250 after warmup, giving the recorded drop boundary at attempt 300. EMA and scheduler advance after every attempt, including skips. Every 50 attempts, clean-validation AP on 22 sources is evaluated. A strictly greater AP replaces the best checkpoint, preserving the earliest maximum. The five condition-specific validation evaluations use the selected EMA. The main test sets are not used in this protocol.

COCO AP uses IoU thresholds 0.50:0.05:0.95 and maxDets 1/10/100. Values are reported in percentage points. Internal AP is the equal mean of clean and five generated-condition APs; external AP is the equal mean of pooled-real and synthetic APs. Seed averaging follows per-run aggregation. Results use Clean-only followed by subset size 1 through 5, with combinations in rain, snow, fog, dust, low_light order. Each configuration lists seeds 0, 1, 2 followed by its mean.
